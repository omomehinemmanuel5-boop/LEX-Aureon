# LexBench Receipt Artifacts

This directory contains cryptographically verifiable benchmark receipts generated by `scripts/lexbench/generate-receipts.ts`.

Each receipt records:
- benchmark
- run ID
- Git commit
- dataset hash
- result hash
- receipt hash (SHA-256)
- workflow run ID
- timestamp

Receipts are generated automatically by `.github/workflows/lexbench-receipts.yml` and uploaded as CI artifacts.
