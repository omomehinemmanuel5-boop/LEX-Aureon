# LexBench v2

This manifest becomes the single source of truth for Lex benchmark evidence.

## Principles

- One schema across every benchmark.
- Reproducible metadata.
- Commit-linked evidence.
- Future trajectory receipts.

## Fields

- dataset
- version
- sample_count
- bare
- governed
- latency
- false_positive
- receipt
- commit

The dashboard, landing page, and future papers should consume this manifest rather than hard-coded numbers.
